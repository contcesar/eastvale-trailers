# Images

Add your real photos here. The site references these paths:

- `hero.jpg` — homepage hero photo (TODO)
- `og.jpg` — social share image, ~1200×630 (TODO)
- `trailers/enclosed.jpg`
- `trailers/flatbed.jpg`
- `trailers/tilt.jpg`
- `trailers/car.jpg`
- `trailers/utility.jpg`
- `trailers/gooseneck.jpg`

Until a photo exists, cards and image slots show a "Photo coming soon"
placeholder, so the site still builds and looks clean. Anything in
`/public` is served from the site root (e.g. `/images/trailers/car.jpg`).
