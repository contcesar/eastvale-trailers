- `eastvale-trailers-logo.png`: header logo (added)
- `hero.png`: homepage hero photo (added)
- `og.jpg`: social share image, about 1200x630 (TODO)
- `trailers/enclosed.jpg`
- `trailers/flatbed.jpg`
- `trailers/tilt.jpg`
- `trailers/car.jpg`

Until a trailer photo exists, cards and image slots show a "Photo coming soon"
placeholder, so the site still builds and looks clean. Anything in `/public` is
served from the site root (for example, `/images/trailers/car.jpg`).
